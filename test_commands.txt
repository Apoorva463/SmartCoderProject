# Backend API Test Commands

## 1. Health Check
curl -X GET http://localhost:8000/health

## 2. Basic Search Test (Moby-Dick content)
curl -X POST http://localhost:8000/api/search \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://httpbin.org/html",
    "query": "blacksmith melville"
  }'

## 3. Generic Search Test
curl -X POST http://localhost:8000/api/search \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://httpbin.org/html", 
    "query": "content text"
  }'

## 4. Test with Different Website
curl -X POST http://localhost:8000/api/search \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://example.com",
    "query": "example domain"
  }'

## 5. Pretty Print JSON Response (if you have jq installed)
curl -X POST http://localhost:8000/api/search \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://httpbin.org/html",
    "query": "blacksmith melville"
  }' | jq '.'
